# Recipe AI

A beautiful web application that suggests recipes based on the ingredients you have at home. Powered by AI and built with React, TypeScript, and Material-UI.

## Features

- Modern, responsive UI with beautiful animations
- Smart recipe suggestions based on available ingredients
- Detailed recipe cards with ingredients and instructions
- Save and manage your favorite recipes

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/recipe-ai.git
cd recipe-ai
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Start the development server:
```bash
npm start
# or
yarn start
```

The application will be available at `http://localhost:3000`.

## Usage

1. Visit the landing page to learn about the application
2. Click "Get Started" to go to the recipe page
3. Add your available ingredients
4. Click "Generate Recipes" to get AI-powered recipe suggestions
5. Browse through the suggested recipes and their details
